## 🔔 เรื่องการแจ้งเตือน (อ่านก่อน)

แอพนี้เป็น static + เก็บข้อมูลในเครื่อง จึงรองรับการแจ้งเตือนได้ 2 ระดับ:

1. **ทำงานได้เลยตอนนี้ (ไม่ต้องมีเซิร์ฟเวอร์):** ขอสิทธิ์แจ้งเตือน แล้วเด้ง Notification เตือนรอบชำระ **เมื่อเปิดแอพ / แอพอยู่เบื้องหลัง** (เช็คอัตโนมัติทุกครั้งที่กลับเข้าแอพ)
2. **เด้งเตือนแม้ปิดแอพสนิท (ต้องต่อเซิร์ฟเวอร์เพิ่ม):** ต้องใช้ **Web Push + VAPID keys + เซิร์ฟเวอร์ส่ง push** — โค้ดฝั่ง Service Worker (`push`, `notificationclick`) เตรียมไว้พร้อมแล้ว เหลือแค่ทำ backend ส่ง push เข้ามา
   - บน iPhone: รองรับ Web Push เฉพาะเมื่อ **ติดตั้งเป็น PWA ลงหน้าจอโฮมแล้ว** (iOS 16.4+)

## 📲 วิธีติดตั้งลงหน้าจอ iPhone

1. เปิดไฟล์ผ่าน **https** (PWA ต้องใช้ https หรือ localhost) — ดูหัวข้อ "เผยแพร่" ด้านล่าง
2. เปิดใน **Safari** → กดปุ่ม **แชร์** (กล่องมีลูกศรขึ้น)
3. เลือก **"เพิ่มลงในหน้าจอโฮม"** → ได้ไอคอนน้องออมบนหน้าจอเหมือนแอพจริง

## 🚀 รันทดสอบในเครื่อง

**แบบธรรมดา** (ไม่มี push เซิร์ฟเวอร์ — แจ้งเตือนแบบ foreground เท่านั้น):
```bash
node server.js
# เปิด http://localhost:4173
```

**แบบมี Web Push จริง** (เด้งเตือนแม้ปิดแอพ):
```bash
cd server
npm install
npm start
# เปิด http://localhost:4173 → ตั้งค่า → เปิดการแจ้งเตือน
```
รายละเอียดดูที่ [server/README.md](server/README.md) — แอพจะตรวจเจอ `/api` อัตโนมัติแล้วสมัคร push ให้เอง

## 💾 ข้อมูล

เก็บในเครื่องผ่าน `localStorage` (คีย์ `oommoney.v1`) — ไม่ส่งออกที่ไหน เป็นส่วนตัว 100%
กด **ตั้งค่า → โหลดข้อมูลตัวอย่าง** เพื่อลองเล่นทุกฟีเจอร์

## 🧮 สูตรคำนวณสุขภาพการเงิน

- **DSR (ภาระหนี้)** = ยอดผ่อนรวมต่อเดือน ÷ รายรับต่อเดือน × 100
- **คะแนนสุขภาพ** = 100 − (DSR × 1.15)
- เกณฑ์: ≤30% ดีเยี่ยม · ≤40% ดี · ≤50% เริ่มตึง · ≤70% เสี่ยงสูง · >70% อันตราย

(อิงหลัก DSR ที่สถาบันการเงินใช้ประเมิน โดยทั่วไปแนะนำให้ภาระหนี้ไม่เกิน 40% ของรายได้)
